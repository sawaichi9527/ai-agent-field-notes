# Interpretation (same on the previous kernel, i.e. not caused by the switch):
# - "Broken broadcast TLBI completion" is the arm64 errata mitigation being
#   APPLIED (kernel knows the CPU needs the safe TLBI path) - a good line.
# - tegra-i2c DMA -19 -> PIO fallback: the SOC's i2c block has no DMA on this
#   platform; both controllers fall back to programmed IO on every boot.
# - the kernel watchdog ("lockup detector") cannot self-init (-19), so the
#   kernel-side watchdog is disabled; the platform still has the SBSA Generic
#   Watchdog via ACPI (seen in the same boot log: "found 1 SBSA generic
#   Watchdog(s)") and systemd uses it for watchdog timeouts.
